# Superfly

Personal brand website. Warm editorial minimalism with strong typography, deliberate light/dark contrast, and space for personal voice.

## Run locally

This is a static site. Open `index.html` in a browser, or serve it with any static server:

```bash
# Python
python3 -m http.server 8000

# Node (if you have npx)
npx serve .
```

## Deploy

Configured for Netlify. Connect the repo or drag the folder. Default domain will be available after first deploy.

## Placeholders

Update bio, Now items, selected work, writing, and social links in `index.html` with real content.
